# ZephyrQuill

ZephyrQuill is a cloud-based, distributed processing engine that utilizes orchestration of complex workflows through a decentralized, broker-based architecture.

ZephyrQuill is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ZephyrQuill.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

ZephyrQuill is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
